DATASET JOINABILITY ANALYSIS
================================================================================
billing.csv: Telecom subscription billing. Entity = subscriber-month.
WA_Fn: Accounts receivable invoices. Entity = invoice.

JOIN KEY CANDIDATES:
  - billing.subscriber_id vs WA_Fn.customerID: INCOMPATIBLE
    billing uses SUB0000001 format, WA_Fn uses 0379-NEVHP format.
    Different ID namespaces, different industries (telecom vs generic AR).
  - No shared temporal key (billing=2025-2026, WA_Fn=2012-2013)
  - No shared domain (telecom billing vs enterprise invoicing)

DECISION: DO NOT JOIN. Keep as separate training datasets.
REASON: Different entity types, different time periods, different industries,
        no shared identifiers. Forcing a join would be scientifically invalid.
